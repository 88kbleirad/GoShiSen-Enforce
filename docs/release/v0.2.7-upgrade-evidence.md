## Forwarding impact of init failure paths (item 2c) — measured

Probe: from the lab LAN netns `gsh_owrt_lan` to `10.0.2.2:8099/proof.txt`
(across the guest's forward hook into slirp). `http=200` = passed,
`http=000 rc=28` = blocked (curl connect timeout). The guest's own
firewall4 forward chain is default-drop, so "nothing installed" is also
blocked; the pass control is the daemon running with an ACCEPT policy.

| State | Forwarding probe |
| --- | --- |
| control A: nothing installed (fw4 default-drop) | blocked (`http=000 rc=28`) |
| control B: 0.2.6-r1 running, ACCEPT policy | **passes (`http=200`)** |
| control C: 0.2.6-r1 running, DROP policy | blocked |
| 0.2.6 old init: `api_port 'abc'` → abort | **blocked** (hook remains; daemon not started) |
| 0.2.7 init: same invalid value → abort | **blocked** (same mechanism; error names the option) |
| 0.2.7 `api_port 0`, DROP policy | blocked (daemon running, listeners off) |
| 0.2.7 ACCEPT policy | **passes (`http=200`)** — positive control on the new binary |
| 0.2.7 config missing + operator runs `goshisen hook cleanup` | passes (`http=200`) — explicit operator action only |

Error messages observed in `logread`:

```
daemon.err goshisen: api_port 'abc' is not a port (0-65535); refusing to start
daemon.err goshisen: service is disabled (goshisen.main.enabled=0)
daemon.warn goshisen: api_port is not set; treating it as 0 (listener disabled)
```

Conclusion: **every init failure path is fail-closed** — a failed start
never opens forwarding; the pre-existing boot guard / daemon hook remain
(forwarding stays blocked). The only way to pass traffic again after a
failed start is the documented recovery: fix the config and restart, or
run `/usr/sbin/goshisen hook cleanup` explicitly (operator action, which
also removes the block). A remote router whose service fails to start
keeps LAN→WAN blocked until the config is fixed — the failure is loud in
`logread` and the router-local management plane (SSH/LuCI/serial) is
never queued, so the operator can always recover remotely.
