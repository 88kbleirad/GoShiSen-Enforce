# GoShiSen-Enforce v0.2.6 — Release Notes

**Status:** published. **Date:** 2026-11-19.
**Type:** S-005 toolchain-fix release (issue #78) — apk payload and both
CLI archives built with go1.27.4.

## What is in v0.2.6

**S-005 toolchain-fix release (issue #78).** The v0.2.5 (and earlier)
v0.2.x OpenWrt apk payloads embedded go1.27.1 and the CLI archives
go1.25.14 — both carrying reachable standard-library vulnerabilities
(see the advisory section below). v0.2.6 ships the apk payload **and**
both CLI archives built with **go1.27.4**, closing the set.

Runtime Go changes since v0.2.5 (all tested; CI evidence on this tag):

1. **queue_num validation:** 65535 is now rejected (range 0..65534) —
   the hook installs an IPv6 queue rule at queue_num+1, and 65535 would
   render `queue to 65536` (S-002). Tests:
   `internal/config/config_test.go`.
2. **Receive-error attribution:** netlink receive errors are now
   attributed correctly in stats (F-002). Tests:
   `internal/packet/capture_test.go`.
3. **Strict port parsing:** policy and config ports are parsed with
   `strconv.Atoi` (F-001). Tests: `internal/policy/parser_test.go`.
4. **go.mod:** `go 1.26.0` + `toolchain go1.27.4`; golang.org/x/net
   v0.62.0, golang.org/x/sys v0.49.0.
5. **Test-only metrics server seam:** `serveMetrics` now binds via
   `net.Listen` and exposes `MetricsAddr` (no behavior change; enables
   the CONNECT/oversized-POST behavior tests in #82).

## Which key is which

- **APK anchor** (`keys/goshisen-apk.pub.pem`, EC P-256, fingerprint
  `542bb7ae...`) verifies the apk. Install at
  `/etc/apk/keys/goshisen-apk.pub.pem`.
- **CLI release key** (`public_key.pem`, Ed25519, fingerprint
  `24215e01...`) verifies the tarballs/checksums/SBOM signatures. The
  two keys are distinct and never interchanged.

## Install

```sh
mkdir -p /etc/apk/keys
wget -O /etc/apk/keys/goshisen-apk.pub.pem \
  https://raw.githubusercontent.com/88kbleirad/GoShiSen-Enforce/v0.2.6/keys/goshisen-apk.pub.pem
openssl pkey -pubin -in /etc/apk/keys/goshisen-apk.pub.pem -outform DER | sha256sum
# must print 542bb7ae9058fee9b4d37ed30b0af44f234ea7cb8866daa1ffc71a7bc37c839d
apk verify --keys-dir /etc/apk/keys goshisen-0.2.6-r1.apk   # OK
apk add goshisen-0.2.6-r1.apk                                # no --allow-untrusted
```

## Reproducibility

Two clean official-SDK container builds (`openwrt/sdk@sha256:a17d6436...`,
sha256-verified Go 1.27.4 tarball mounted ro at /go-host,
GOTOOLCHAIN=local) of the v0.2.6 pin are **byte-identical for both the
apk and the payload**:

- apk sha256 `ca5fd872795d1f992ca3f2446b5bae3e368aacb38942a6a7f58eedbf8180e32f`
- payload sha256 `4ebf71b0cc5911518b9765f18f79aadee3d36d66e387cc657fcc3824e393f179`

The apk is built with an **official Go tarball mounted into the pinned
SDK container** (`PKG_BUILD_DEPENDS:=golang/host` is a build dependency,
not the compiler; `Build/Compile` invokes `go` from PATH), with
`STRIP:=true` and no `-buildid=` so the payload keeps readable
buildinfo for the sign-time gates.

## Security advisory (S-005) — v0.2.5 and earlier

Full per-vulnerability classification, per-release scan table and
severity statement: `docs/security/advisory-v0.2.5-go-toolchain.md`.
Summary: v0.2.5 (and earlier v0.2.x) apk payloads embed go1.27.1 and
CLI archives go1.25.14, carrying 11 reachable stdlib vulnerability IDs
(source-mode). **No remote exploit exists with the default
configuration** — both HTTP listeners disabled by default, loopback-only
when enabled, no outbound connections, no TLS. Severity: Low (default) /
Medium (misconfigured non-loopback `api_host`). **v0.2.6 is the fix
version:** apk payload and both CLI archives built with go1.27.4.

## Known limitations

- Kernel matrix verified: **6.12.112** on OpenWrt 25.12.6 x86/64 only.
- arm64: verified only under QEMU TCG, no hardware.
- The apk is deliberately **not in `checksums.txt`** (different key /
  trust domain); its sha256 lives here and in the signing-gate
  provenance.
- Stateful IPv6 requires the bidirectional ESTABLISHED/RELATED rule in
  the policy.
- Tag `v0.2.6` is **annotated but unsigned** (SSH allowed-signers not
  yet configured by the maintainer; see docs/release/signed-tags-plan.md).
- Build-from-source with `GOTOOLCHAIN=local` on a Go 1.26.x toolchain
  uses the unpatched 1.26.x stdlib — `toolchain go1.27.4` is a
  preference, not an enforced minimum, under `GOTOOLCHAIN=local`;
  use Go 1.27.4 (or `GOTOOLCHAIN=auto`) to get the S-005 toolchain fix.
