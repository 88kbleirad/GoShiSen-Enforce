(sha256 `b514edc10b9b345f6ed52712d92a702fb2bf7ac850273181f4ce290e816d3d80`) with

**Result:** upgrade succeeds and the daemon comes back as 0.2.8 with the queue
rebound; 117/118 probes stayed 200. The one failure is a ≈1–3 s gap while the
package stops and restarts the service (packets already queued are dropped —
fail-closed), the same stop/start window documented for previous releases, not
a v0.2.8 regression. The package's lifecycle script blocks
(`preinst`/`postinst`/`postinst-notify-listener-defaults`/`prerm` in
`openwrt/Makefile`) are **identical between the v0.2.7 and v0.2.8 tags** (block
comparison, not prose); the v0.2.8 delta in the installed tree is the binary,
`init.d` (api_token → 0600 rendering) and `/etc/config/goshisen` (commented
`api_token`/D1 options), confirmed with `apk extract` + `diff -rq`.
